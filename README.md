# NOVA HABITAT

생활 방식에 맞춰 미래 주거를 배치하고, 채광·온습도·에너지·재배 공간을 시험하는 설계 스튜디오.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 콘셉트를 고른 뒤 가구를 배치하고, 벽·문·창·구역을 고칩니다. 저장은 브라우저에 남고, JSON으로 내보내거나 가져올 수 있습니다.

## 테스트

```bash
npm run test:app
```

기하·추정 로직 테스트 7개와 공통 모듈 테스트를 돌립니다. Grok Build 환경 밖에서도 통과합니다.
`npm test`는 Grok Build 샌드박스 전용 검사를 함께 돌리므로 그 환경 밖에서는 실패합니다.
